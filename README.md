# Pathfinding Lab

一个不依赖框架的寻路算法可视化网站，用逐步动画展示 BFS、Greedy、Dijkstra 和 A* 的搜索过程。

## 功能

- 在同一张网格地图中切换四种算法；
- 显示当前节点、待考察集合、已访问集合和最终路径；
- 地图动画与教学伪代码同步高亮，并实时展示队列或优先队列内容；
- 支持运行、暂停、单步，以及0.25×、0.5×、1×、1.5×、2× 五档速度；
- 内置白板、权重、障碍、权重 + 障碍四种地图预设；
- 可以绘制障碍、权重地形，移动起点与终点；
- 保留随机地图和完整的自定义编辑能力；
- 实时显示访问节点数、路径代价与算法评分；
- 响应式布局，支持桌面与移动端。

## 本地运行

项目使用 ES Modules，需要通过本地 HTTP 服务打开：

```bash
python3 -m http.server 8000
```

浏览器访问 <http://localhost:8000>。

运行算法测试：

```bash
npm test
```

## 状态颜色

- 浅蓝：已经发现、等待处理的节点（frontier）
- 深蓝：已经完成处理的节点（visited）
- 黄色：当前节点或最终路径
- 紫色：进入该格子的移动代价为 5

普通格移动代价为 1。BFS 会忽略权重；Greedy 只用启发值决定搜索方向；Dijkstra 和 A* 会计算权重，因此可以直观看到“最少步数”“目标方向”和“最低代价”的区别。
